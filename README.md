# Personal Finance Analysis with Python

This repository contains a **personal finance analysis project** that uses **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn** to analyze income and expense data. The project tracks spending patterns, visualizes monthly income vs. expenses, and analyzes cumulative balance trends over time.

## Project Overview

In this project, I used real-world financial data to:
- Track daily and monthly income/expenses.
- Visualize spending patterns in categories such as **Food**, **Transport**, **Entertainment**, etc.
- Analyze the cumulative balance trend over time.

### Tools Used:
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)
- **Google Colab** for interactive notebook execution
- **GitHub** for version control and sharing the project
